    ⊘ What it will NOT do

      AI-DLC v2 ships a 14-agent roster: 11 broadly-capable domain experts that execute stage work, 2 review-only quality-gate agents, and the adaptive-workflows composer. The conductor delegates every stage to a lead agent; others join as support. Click an agent to highlight the stages it leads and supports on the map.

      Tier governs model/effort: judgment agents inherit your session's own model and effort; templated agents (delivery, pipeline-deploy, operations) use a mid-size model at reduced effort on Claude Code / Codex / opencode. L = leads, S = supports. The two reviewers and the composer are not stage leads.

      Every dial in this map is plain data in a file — no code. Three things set your configuration: per-run CLI flags (fastest), the scope & stage files (durable defaults), and settings.json (project default). The resolved choices for a run are recorded in that intent's aidlc-state.md.
